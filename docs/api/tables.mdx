## Add

```typescript
addTable(props: {
  tableName: string;
  workbookName: string;
  sheetName: string;
  start: string;
  numRows: SpreadsheetRangeEnd;
  numCols: number;
}): void
```

```typescript
engine.addTable({
  tableName: "Sales",
  workbookName: "Budget",
  sheetName: "Q1",
  start: "A1",
  numRows: { type: "number", value: 20 },
  numCols: 4,
});
```

`start` is A1 text. The first row supplies column headers. `numRows` can be
finite or `{ type: "infinity" }`; a finite value counts the data rows below
the header row.

## Read

```typescript
hasTable(opts: { tableName: string; workbookName: string }): boolean
getTable(opts: { tableName: string; workbookName: string }): TableDefinition | undefined
getTables(workbookName: string): Map<string, TableDefinition>
isCellInTable(address: CellAddress): TableDefinition | undefined
```

```typescript
interface TableDefinition {
  name: string;
  start: { rowIndex: number; colIndex: number };
  headers: Map<string, { name: string; index: number }>;
  endRow: SpreadsheetRangeEnd;
  sheetName: string;
  workbookName: string;
}
```

## Rename

```typescript
renameTable(
  workbookName: string,
  names: { oldName: string; newName: string },
): void
```

Rewrites structured references to the table in formulas and named expressions,
including `[Budget]Sales[Qty]` references in other workbooks. References to a
table of the same name in another workbook are left alone.

## Update

```typescript
updateTable(opts: {
  tableName: string;
  workbookName: string;
  sheetName?: string;
  start?: string;
  numRows?: SpreadsheetRangeEnd;
  numCols?: number;
}): void
```

Moves or resizes an existing definition and invalidates dependent formulas.
Header names are re-read from cell values. Existing cell contents in newly
included rows or columns are preserved and become part of the table. A resize
is rejected if the resulting table would overlap another table.

To resize a table and write its new contents as one update and one undo step,
make both calls inside `transact`, resizing first. See
[Resize and replace the contents](/concepts/tables#resize-and-replace-the-contents).

## Remove

```typescript
removeTable(opts: { tableName: string; workbookName: string }): void
```

Removes the definition. Stored formulas are not rewritten to A1 ranges.
Aggregates over the missing table currently behave like empty ranges in common
cases.

## Reset all tables

```typescript
resetTables(tables: Map<string, Map<string, TableDefinition>>): void
```

Replaces the engine's complete table registry. The outer map is keyed by
workbook; the inner map by table name. Useful during custom deserialization,
but `resetToSerializedEngine` is easier for whole-engine persistence.

## Structured reference syntax

```excel
=SUM(Sales[Qty])
=[@Qty]*[@Price]
=Sales[@Qty]
=Sales[#Headers]
=Sales[#Data]
=SUM([Budget]Sales[Qty])
```

See [Tables](/concepts/tables) for current-row behavior, infinite tables,
tables in other workbooks and edge cases.
