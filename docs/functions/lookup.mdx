## Count

### `COUNT`

Counts numeric values.

```excel
=COUNT(value1, [value2], ...)
=COUNT(B2:B6) // 5 for five numeric cells
```

### `COUNTA`

Counts the values that are not empty: numbers, text, logical values and
errors.

```excel
=COUNTA(value1, [value2], ...)
```

Given `North`, `10`, `TRUE`, a formula returning `""`, an empty cell and
`#VALUE!` in `A1:A6`:

```excel
=COUNTA(A1:A6)          // 5
=COUNTA(A:A)            // 5
=COUNTA(1, "", TRUE)    // 3
=COUNTA(SEQUENCE(3,2))  // 6
```

- In a range, empty cells are not counted, but a cell whose formula returns
  `""` is, as in Excel. Cells that other formulas spill onto count like any
  populated cell, and errors inside a range are counted rather than
  propagated.
- A spilled argument, such as `SEQUENCE`, `UNIQUE` or `TOCOL`, counts its
  cells.
- A value passed directly counts once, including `""` and an error value. A
  reference to an empty cell counts `0`.

<Warning>
  The engine reads an empty cell as `""`, so a direct reference to a single
  cell whose formula returns `""` counts `0`, where Excel counts `1`. Inside a
  range such a cell is counted. A reference to the cell a formula spills from
  counts the whole spill: with `C1` holding `=SEQUENCE(5)`, `=COUNTA(C1)` is
  `5`, where Excel needs `C1#` for that and returns `1`. `=COUNTA()` returns
  `#VALUE!`; Excel rejects the formula.
</Warning>

### `COUNTIF`

```excel
=COUNTIF(criteria_range, criteria)
```

```excel
=COUNTIF(A2:A6,"North") // 2
=COUNTIF(B2:B6,">30")   // 2
```

### `COUNTIFS`

```excel
=COUNTIFS(criteria_range1, criteria1, [criteria_range2, criteria2], ...)
```

```excel
=COUNTIFS(A2:A6,"South",B2:B6,">30") // 1
```

All criteria must match the same row/position.

### Empty criteria

A criterion that is empty matches empty cells. That holds for a reference to an
empty cell, for `""` and for `"="`. `"<>"` matches the cells that are not
empty. Given `x`, `y` and three empty cells in `A1:A5`, with `C1` empty:

```excel
=COUNTIF(A1:A5,C1)    // 3
=COUNTIF(A1:A5,"")    // 3
=COUNTIF(A1:A5,"=")   // 3
=COUNTIF(A1:A5,"<>")  // 2
```

<Warning>
  Excel reads a reference to an empty cell as the criterion `0`, so
  `=COUNTIF(A1:A5,C1)` is `0` there and only `""` or `"="` count the blanks.
  This engine does not turn an empty cell into `0` anywhere, criteria
  included. The same rule applies to `COUNTIFS`, `SUMIF(S)`, `AVERAGEIF(S)`,
  `MAXIFS`, `MINIFS`, `MAXIF` and `MINIF`. Guard a criterion that can be
  empty, such as `=IF(C1="","",COUNTIF(A1:A5,C1))`, or put a value in the
  criteria cell.
</Warning>

## `INDEX`

Returns the value at a position in a range.

```excel
=INDEX(array, row_num, [column_num])
```

```excel
=INDEX(B2:B6,3) // 30
```

Row and column numbers are 1-based within the supplied array.

A `row_num` or `column_num` of `0` selects a whole column or row, as in Excel,
and an omitted one counts as `0`. Given the regions in `A2:A6` and the units
`10,20,30,40,50` in `B2:B6`:

```excel
=INDEX(A2:B6,0,2)      // spills the second column: 10,20,30,40,50
=INDEX(A2:B6,,2)       // the same
=INDEX(A2:B6,4,0)      // spills the fourth row: East, 40
=SUM(INDEX(A2:B6,,2))  // 150
```

A selection from a range behaves like that range, so `=INDEX(A2:B6,,2)` reads
like `B2:B6`. A selection from a computed array spills its cells:
`=INDEX(SEQUENCE(3,3),,2)` spills `2`, `5`, `8`.

## `MATCH`

Returns the 1-based position of a value in a lookup range.

```excel
=MATCH(lookup_value, lookup_array, [match_type])
```

```excel
=MATCH("East",A2:A6,0) // 4
```

Use match type `0` for an exact match. Leaving `match_type` out makes it `1`,
the largest value less than or equal to the lookup value. An omitted
`match_type`, written as a trailing comma, is `0`, as in Excel:

```excel
=MATCH(25,B2:B6)   // 2
=MATCH(25,B2:B6,)  // #N/A, an exact match finds no 25
```

An omitted `lookup_value` is the number `0`: `=MATCH(,B2:B6,0)` looks for a
`0`.

### Approximate match

Match types `1` and `-1` search the way Excel does, with a binary search: they
look at the middle cell, go on in the half where the value would be, and
return where the search ends. On data sorted ascending (`1`) or descending
(`-1`) that is the closest value, the largest one less than or equal to the
lookup value or the smallest one greater than or equal to it, and the last of
equal values next to each other. Neither Excel nor this engine checks the
order, so unsorted data gives the position Excel gives. Given `MAP-994`,
`MAP-10977` and `MAP-320` in `A1:A3`:

```excel
=MATCH("MAP-994",A1:A3)    // 3, as in Excel
=MATCH("MAP-994",A1:A3,0)  // 1
```

Use match type `0` to find a value in unsorted data. Blank cells, errors and
values of another type than the lookup value are stepped over, so a lookup
value larger than any in a column finds the column's last number or text,
whatever the order:

```excel
=MATCH(9.99E+307,B:B)  // the position of the last number in column B
=MATCH("Ω",A:A)        // the position of the last text in column A
```

<Note>
  Where the search goes depends on the length of the range. This engine has no
  sheet limit and searches an unbounded range such as `B:B` up to its last
  non-empty cell, so on unsorted data a whole-column `MATCH` can return a
  different position than Excel. Bounded ranges and table columns are
  searched like in Excel.
</Note>

## `XLOOKUP`

```excel
=XLOOKUP(
  lookup_value,
  lookup_array,
  return_array,
  [if_not_found],
  [match_mode],
  [search_mode]
)
```

```excel
=XLOOKUP("East",A2:A6,B2:B6)        // 40
=XLOOKUP("West",A2:A6,B2:B6,"none") // "none"
```

Lookup and return arrays should have corresponding shapes. Cells are paired by
position, blank cells included, so ranges with gaps such as
`=XLOOKUP("East",A:A,B:B)` return the cell next to the match. A blank cell in
`return_array` is returned as `""`, where Excel shows `0`.

`if_not_found` is used only when nothing matches, so an error there does not
affect a found value. An omitted optional argument takes its default, as in
Excel: `=XLOOKUP("West",A2:A6,B2:B6,,1)` returns `#N/A` when nothing matches.
An omitted `lookup_value` finds the first blank cell of `lookup_array`.

<Warning>
  `XLOOKUP` compares text case-sensitively: `=XLOOKUP("east",A2:A6,B2:B6)`
  returns `#N/A`. Excel, and `MATCH` in this engine, ignore case.
</Warning>

## `VLOOKUP`

Looks for a value in the first column of a table and returns the cell in the
same row of another column.

```excel
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
```

With the regions in `A2:A6` and the units in `B2:B6`:

```excel
=VLOOKUP("East",A2:B6,2,FALSE)  // 40
=VLOOKUP("east",A2:B6,2,FALSE)  // 40, text ignores case
=VLOOKUP("South",A2:B6,2,FALSE) // 20, the first match
=VLOOKUP("West",A2:B6,2,FALSE)  // #N/A
=VLOOKUP("East",A:B,2,FALSE)    // 40, whole columns work too
```

`range_lookup` `FALSE` (or `0`) asks for an exact match. `TRUE`, any other
number, or leaving it out finds the largest value less than or equal to
`lookup_value` in a first column sorted in ascending order:

```excel
=VLOOKUP(72,{0,"F";60,"D";70,"C";80,"B";90,"A"},2)  // "C"
```

The first column is searched like `MATCH` searches its `lookup_array`: exact
matching is `MATCH` type `0` and approximate matching type `1`, values only
match values of the same type, and `lookup_value` must be a number or text. An
omitted `range_lookup`, written as a trailing comma, is `FALSE`, as in Excel:
`=VLOOKUP("East",A2:B6,2,)` is an exact match.

`col_index_num` counts from `1`, the first column, and is truncated. Below `1`
it returns `#VALUE!` and beyond the last column `#REF!`, whether or not the
value is found. A blank cell in the returned column is returned as `""`, where
Excel shows `0`.

An array `lookup_value` or `col_index_num` looks up every element and spills:

```excel
=VLOOKUP({"North";"East"},A2:B6,2,FALSE)  // spills 10, 40
=VLOOKUP("East",A2:B6,{1,2},FALSE)        // spills East, 40
```

<Warning>
  Wildcards are not supported: `=VLOOKUP("E*",A2:B6,2,FALSE)` looks for the
  text `E*` and returns `#N/A`, as `MATCH` does here. Excel finds `East`.
</Warning>

## Structured ranges

Lookup and count functions accept table columns:

```excel
=COUNT(Sales[Qty])
=XLOOKUP("Widget",Sales[Product],Sales[Price],"not found")
```

## Not registered

<Note>
  `HLOOKUP` is not registered and returns `#NAME?`. Use `XLOOKUP` or an
  `INDEX` + `MATCH` combination.
</Note>
