## `ADDRESS`

Builds reference text, in A1 or R1C1 style, from 1-based row and column
numbers.

```excel
=ADDRESS(row_num, column_num, [abs_num], [a1], [sheet_text])
```

`abs_num` controls which parts are absolute, and `a1 = FALSE` switches to R1C1
style, where a relative part is written in brackets:

| `abs_num` | A1 style | R1C1 style |
| --- | --- | --- |
| `1` or omitted | `$C$2` | `R2C3` |
| `2` | `C$2` | `R2C[3]` |
| `3` | `$C2` | `R[2]C3` |
| `4` | `C2` | `R[2]C[3]` |

```excel
=ADDRESS(2,3)                  // "$C$2"
=ADDRESS(2,3,4)                // "C2"
=ADDRESS(2,3,1,TRUE,"Sheet2") // "Sheet2!$C$2"
=ADDRESS(2,3,1,FALSE)         // "R2C3"
```

Omitted arguments take their defaults, as in Excel: `=ADDRESS(2,3,,FALSE)` is
`"R2C3"` and `=ADDRESS(2,3,,,"Sheet2")` is `"Sheet2!$C$2"`. `abs_num` must be
a number from 1 to 4 and `a1` a logical value or a number; anything else
returns `#VALUE!`.

## `INDIRECT`

Resolves A1 text into a reference.

```excel
=INDIRECT(ref_text, [a1])
```

```excel
=INDIRECT("B3") // value of B3
```

The text may be produced by another formula:

```excel
=INDIRECT(ADDRESS(ROW(),COLUMN()-1))
```

R1C1 text is not supported: `=INDIRECT("R2C3",FALSE)` returns `#VALUE!`.
Because the reference is produced at runtime, prefer direct references when
static dependency analysis matters.

## `OFFSET`

Returns a reference displaced from an origin.

```excel
=OFFSET(reference, rows, cols, [height], [width])
```

```excel
=OFFSET(A1,1,1)          // reference B2
=SUM(OFFSET(A1,1,1,3,1)) // sum B2:B4
```

Verified with `B2:B4 = 10,20,30`, the second formula returned `60`.

An omitted `rows` or `cols` is `0`, as in Excel, so `=OFFSET(A1,,1)` is `B1`.
An omitted `height` or `width` keeps the size of `reference`. `rows` and `cols`
must be numbers, and `height` and `width` positive numbers; anything else
returns `#VALUE!`.

A multi-cell offset is an array/reference and can be consumed by aggregates or
spill from a cell.

## Address helper APIs

For application code, prefer exported TypeScript helpers over formula text:

```typescript
parseCellReference("C5"); // { colIndex: 2, rowIndex: 4 }
getCellReference({ colIndex: 2, rowIndex: 4 }); // "C5"
columnToIndex("AA"); // 26
indexToColumn(26);    // "AA"
```
