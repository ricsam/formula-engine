## `SEQUENCE`

Generates a rectangular array of sequential numbers, filled row by row.

```excel
=SEQUENCE(rows, [columns], [start], [step])
```

| Argument | Meaning | Default |
| --- | --- | --- |
| `rows` | output height | `1` when omitted |
| `columns` | output width | `1` |
| `start` | first number | `1` |
| `step` | increment | `1` |

```excel
=SEQUENCE(3)          // spills 1,2,3 downward
=SEQUENCE(3,2,1,1)   // 3 × 2 grid
=SEQUENCE(4,1,10,10) // 10,20,30,40
```

`=SEQUENCE(3,2,1,1)` spills row-major:

| | |
| --- | --- |
| 1 | 2 |
| 3 | 4 |
| 5 | 6 |

Only the top-left anchor stores the formula. The neighbouring values are spill
members and can be referenced normally.

### Omitted arguments

Any argument can be omitted by leaving it empty. It then takes its default, as
in Excel:

```excel
=SEQUENCE(,3)      // one row: 1,2,3
=SEQUENCE(3,,10)   // one column: 10,11,12
=SEQUENCE(2,3,,2)  // 1,3,5 in the first row, 7,9,11 in the second
```

`=SEQUENCE()`, with no arguments at all, returns `#VALUE!`. A one-cell
sequence such as `=SEQUENCE(,)` is the single value `1`.

### Argument rules

`rows` and `columns` are truncated to whole numbers and must be at least `1`;
`=SEQUENCE(0)` returns `#VALUE!`. Every argument must be a single value:
`=SEQUENCE(A1:A2)` returns `#VALUE!`, where Excel builds one sequence per
element.

## `UNIQUE`

Returns the distinct rows, or columns, of a range or array.

```excel
=UNIQUE(array, [by_col], [exactly_once])
```

| Argument | Meaning | Default |
| --- | --- | --- |
| `array` | range or array to deduplicate | required |
| `by_col` | `TRUE` compares columns instead of rows | `FALSE` |
| `exactly_once` | `TRUE` keeps only entries occurring once | `FALSE` |

```excel
=UNIQUE(A1:A5)              // distinct values down a column
=UNIQUE(A1:C1, TRUE)        // distinct values across a row
=UNIQUE(A1:B4, FALSE, TRUE) // rows appearing exactly once
```

Entries keep the order of their first occurrence, and the first occurrence is the
one returned. Given `a`, `b`, `a`, `c`, `b` in `A1:A5`, `=UNIQUE(A1:A5)` spills
`a`, `b`, `c`.

### Rows versus columns

With a 2-D input, `UNIQUE` compares whole rows by default, so a row survives only
when it differs from every earlier row in at least one column. `by_col` switches
the comparison to whole columns. `by_col` also decides the orientation of a 1-D
input: a single row is one entry unless `by_col` is `TRUE`.

`by_col` and `exactly_once` accept booleans, or `1` and `0`. An omitted flag
takes its default, `FALSE`, so `=UNIQUE(A1:A5,,TRUE)` compares rows and keeps
the entries that occur once.

### Comparison rules

Values must share a type to be equal, so `1`, `"1"` and `TRUE` are three distinct
values. Text compares case-insensitively: `"Ab"` and `"aB"` collapse into one
entry, retaining the casing of the first. Empty cells read as `""`, which is a
value like any other.

### Unbounded ranges

`array` may be unbounded along the dimension being deduplicated, because the
unbounded tail of empty rows or columns collapses into a single empty entry:

```excel
=UNIQUE(A:A)        // fine
=UNIQUE(1:1, TRUE)  // fine
```

The other dimension must be bounded, since it determines the result's width or
height. `=UNIQUE(1:2)` and `=UNIQUE(A:B, TRUE)` return `#VALUE!`.

<Note>
  An unbounded empty tail counts as more than one occurrence, so `exactly_once`
  never returns the empty entry for an unbounded `array`.
</Note>

### Errors

An error anywhere in `array` propagates to the result. When `exactly_once`
removes every entry, `UNIQUE` returns `#CALC!`.

```excel
=UNIQUE(A1:A4, FALSE, TRUE) // #CALC! when every value repeats
```

## `FILTER`

Returns the rows of an array for which a condition is true, or its columns.

```excel
=FILTER(array, include, [if_empty])
```

| Argument | Meaning | Default |
| --- | --- | --- |
| `array` | range or array to filter | required |
| `include` | one column as tall as `array`, which selects rows, or one row as wide as `array`, which selects columns | required |
| `if_empty` | returned when nothing is selected | `#CALC!` |

Given regions `North`, `South`, `North`, `East`, `North` in `A2:A6`, units
`10`, `20`, `30`, `40`, `50` in `B2:B6` and prices `1.5`, `2.5`, `3.5`, `4.5`,
`5.5` in `C2:C6`, `=FILTER(A2:C6, A2:A6="North")` spills:

| | | |
| --- | --- | --- |
| North | 10 | 1.5 |
| North | 30 | 3.5 |
| North | 50 | 5.5 |

```excel
=FILTER(B2:B6, C2:C6>3)                   // 30, 40, 50
=FILTER(B2:B6, A2:A6="West", "none")      // "none"
=FILTER(B2:B6, A2:A6="West")              // #CALC!
=SUM(FILTER(B2:B6, A2:A6="North"))        // 90
=STDEV.S(FILTER(B2:B6, A2:A6="North"))    // 20
=ROWS(FILTER(A2:C6, A2:A6="North"))       // 3
=FILTER(A2:C6, {TRUE,FALSE,TRUE})         // columns A and C
```

`include` values are tested like `IF` conditions: `FALSE`, `0` and empty
cells exclude, every other value includes. `if_empty` is evaluated only when
nothing is selected; an omitted one, written as a trailing comma, keeps the
`#CALC!` default. A one-cell result is a single value rather than a spill.

An error in `include` is the result, even in a row that would not be selected,
as in Excel. Errors in `array` stay in their cells. An `include` that is not
one row or one column of the right size returns `#VALUE!`.

### Combining conditions

Excel workbooks usually combine conditions by multiplying them, as in
`(A2:A6="North")*(B2:B6>20)`. Booleans are not numbers in this engine, so that
returns `#VALUE!`. Combine conditions with `IF` instead:

```excel
=FILTER(B2:B6, IF(A2:A6="North", B2:B6>20))          // both: 30, 50
=FILTER(B2:B6, IF(A2:A6="South", TRUE, A2:A6="East")) // either: 20, 40
```

### Unbounded ranges

Whole columns work: `=FILTER(B:B, A:A="North")` spills `10`, `30`, `50` and
grows as rows are added. `include` is read by its populated cells, and the
cells it leaves out count as blank, so they are never selected. Both heights
are unbounded, so ranges such as `B2:B` and `A2:A` must start in the same row
to line up.

<Warning>
  - Excel returns `#VALUE!` for text in `include`; this engine selects the rows
    with non-empty text, as `IF` treats it as `TRUE`.
  - Selected cells that are empty read as `""`, where Excel shows `0`, and
    aggregates skip them: `COUNTA(FILTER(...))` counts the populated selected
    cells of a range. `ROWS(FILTER(...))` counts every selected row.
</Warning>

## `TOCOL`

Returns the cells of a range or array as a single column.

```excel
=TOCOL(array, [ignore], [scan_by_column])
```

| Argument | Meaning | Default |
| --- | --- | --- |
| `array` | range or array to flatten | required |
| `ignore` | `0` keeps every cell, `1` skips blanks, `2` skips errors, `3` skips both | `0` |
| `scan_by_column` | `TRUE` reads the array column by column instead of row by row | `FALSE` |

Given `1`, `2` in `A1:B1` and `3`, `4` in `A2:B2`:

```excel
=TOCOL(A1:B2)        // 1,2,3,4
=TOCOL(A1:B2,,TRUE)  // 1,3,2,4
```

An omitted option keeps its default, as `ignore` does in the second formula.
`ignore` accepts numbers, which are truncated, `TRUE` and `FALSE` as `1` and
`0`, and an empty value as `0`. `scan_by_column` accepts booleans, or numbers,
where `0` is `FALSE`. Any other value, including an `ignore` of `4`, returns
`#VALUE!`.

### Skipping blanks and errors

Given `a`, `#VALUE!`, an empty cell and `b` in `A1:A4`:

```excel
=TOCOL(A1:A4)     // a, #VALUE!, (empty), b
=TOCOL(A1:A4, 1)  // a, #VALUE!, b
=TOCOL(A1:A4, 2)  // a, (empty), b
=TOCOL(A1:A4, 3)  // a, b
```

Errors that are kept stay error cells of the result. The engine reads an empty
cell as `""`, so a cell holding `""`, for example from a formula, is skipped as
a blank too. Blanks that are kept spill as `""`, where Excel shows `0`.

When nothing is left, `TOCOL` returns `#CALC!`. A one-cell result is a single
value rather than a spill, and a single value or error passed as `array` is a
1 × 1 array.

### Unbounded ranges

`array` may be an unbounded range such as `A:A`, `A2:A` or `A:B`. Skipping
blanks drops the empty tail, so the result is bounded:

```excel
=TOCOL(A:A, 1)        // the non-blank cells of column A
=TOCOL(A:B, 1)        // A1, B1, A2, B2, ... without the blanks
=TOCOL(A:B, 1, TRUE)  // column A, then column B, without the blanks
```

Keeping blanks gives an unbounded result. That works only when the scan reaches
every cell: a single row or column, a bounded number of columns read row by
row, as in `=TOCOL(A:B)`, or a bounded number of rows read column by column,
as in `=TOCOL(1:2,,TRUE)`. Otherwise the result is `#VALUE!`: in
`=TOCOL(A:B, 0, TRUE)` the first column never ends, so column B would never be
reached.

## `TOROW`

Returns the cells of a range or array as a single row.

```excel
=TOROW(array, [ignore], [scan_by_column])
```

`TOROW` takes the same arguments as `TOCOL` and follows the same rules for
blanks, errors, `#CALC!` and unbounded ranges. Only the layout differs. With the
same `A1:B2`:

```excel
=TOROW(A1:B2)        // 1,2,3,4 across one row
=TOROW(A1:B2,,TRUE)  // 1,3,2,4 across one row
```

## `HSTACK`

Appends arrays side by side, from left to right.

```excel
=HSTACK(array1, [array2], ...)
```

The result has as many rows as the tallest argument and as many columns as all
arguments together. Given `1`, `2`, `3` in `A1:A3` and `x`, `y` in `B1:B2`,
`=HSTACK(A1:A3, B1:B2)` spills:

| | |
| --- | --- |
| 1 | x |
| 2 | y |
| 3 | #N/A |

As in Excel, a shorter argument is padded with `#N/A` below its last row. A
single value is a 1 × 1 array and is not repeated down:
`=HSTACK(A1:A3, "total")` holds `"total"` in the first row and `#N/A` below
it. A one-cell result is a single value rather than a spill.

An omitted argument, as in `=HSTACK(A1:A2,,B1:B2)`, returns `#VALUE!`, as in
Excel. Pass `""` for an empty cell instead; like any single value, it fills
only the first row.

An argument with unbounded rows, such as `A:A`, makes the result unbounded, with
`#N/A` below the shorter arguments. Only the last argument may have unbounded
columns, such as `1:1`, since no column could follow it; otherwise the result is
`#VALUE!`.

## `TRANSPOSE`

Swaps the rows and columns of a range or array: the first row becomes the first
column.

```excel
=TRANSPOSE(array)
```

Given `1`, `2`, `3` in `A1:C1` and `4`, `5`, `6` in `A2:C2`,
`=TRANSPOSE(A1:C2)` spills:

| | |
| --- | --- |
| 1 | 4 |
| 2 | 5 |
| 3 | 6 |

```excel
=TRANSPOSE(SEQUENCE(1,3))       // 1, 2, 3 down a column
=SUM(TRANSPOSE(A1:C2))          // 21
=A1:A2*TRANSPOSE(A1:A2)         // 2 × 2: 1, 4 in the first row, 4, 16 in the second
```

Each cell of the result reads its source cell when it is read, so the spill
follows edits like the range itself. A single value is returned as is, errors
stay in their cells, and empty cells read as `""`, where Excel shows `0`.
Aggregates read the cells the argument provides, for a range its populated
cells. `=TRANSPOSE(A:A)` is a single row with unbounded columns.

## Spill obstruction

Any content in the target area causes the anchor to return `#SPILL!`. The
anchor spills again by itself once the area is free: when the blocking content
is cleared, or when another spill that occupied the area goes away.

See [Spilling](/concepts/spilling) for broadcasting, references, obstruction
and recovery.
