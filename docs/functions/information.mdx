## `ROW`

Returns a 1-based row number.

```excel
=ROW([reference])
```

```excel
=ROW()    // row of the formula cell
=ROW(B4)  // 4
```

When no reference is supplied, context matters. A formula in `E36` returned
`36`.

## `COLUMN`

Returns a 1-based column number.

```excel
=COLUMN([reference])
```

```excel
=COLUMN()    // column of the formula cell
=COLUMN(C1)  // 3
```

A formula in column E returned `5`.

## `ROWS`

Returns the number of rows in a reference or array.

```excel
=ROWS(array)
```

```excel
=ROWS(A1:B10)                     // 10
=ROWS(SEQUENCE(5,2))              // 5
=ROWS({1,2;3,4;5,6})              // 3
=ROWS(5)                          // 1
=ROWS(UNIQUE(TOCOL(A2:A100, 1)))  // the number of distinct non-blank values
```

A range is measured without reading its cells, so `=ROWS(A1:B10)` is `10`
whatever the cells hold, even when the formula sits inside `A1:B10`. A spilled
result counts the rows of the area it spills onto. A single value is a 1 × 1
array.

## `COLUMNS`

Returns the number of columns in a reference or array. `COLS` is an alias.

```excel
=COLUMNS(array)
```

```excel
=COLUMNS(A1:C10)         // 3
=COLS(A1:C10)            // 3
=COLUMNS(SEQUENCE(5,2))  // 2
=COLUMNS({1,2,3})        // 3
```

`COLUMNS` measures ranges, spilled results and single values the same way as
`ROWS`.

### Differences from Excel

These apply to both `ROWS` and `COLUMNS`:

- A reference to the cell a formula spills from measures the whole spill. With
  `C1` holding `=SEQUENCE(5)`, `=ROWS(C1)` is `5`, where Excel needs `C1#`
  for that and returns `1`. The result follows the spill when it changes size,
  and is `#SPILL!` while the spill is blocked.
- An unbounded dimension counts as infinity, because the engine has no sheet
  size limit: `=ROWS(A:A)`, `=ROWS(A2:A)` and `=COLUMNS(1:1)` return
  `"INFINITY"`. Excel returns `1048576` for `ROWS(A:A)` and `16384` for
  `COLUMNS(1:1)`.
- An error argument is returned as the result. A single-cell reference is
  evaluated to find out whether it spills, so a reference to a cell holding an
  error returns that error too, where Excel returns `1`.

## `ISNUMBER`

Returns `TRUE` when a value is a number.

```excel
=ISNUMBER(value)
```

```excel
=ISNUMBER(42)                       // TRUE
=ISNUMBER("42")                     // FALSE: text that looks like a number is text
=ISNUMBER(1/"x")                    // FALSE: errors are tested, not propagated
=ISNUMBER(MATCH("x", A1:A9, 0))     // whether x occurs in A1:A9
=IF(ISNUMBER(B1), B1*2, "")         // guard a calculation
```

`INFINITY` and `-INFINITY`, which this engine returns for a division by zero,
are numbers.

## `ISBLANK`

Returns `TRUE` when a value is blank.

```excel
=ISBLANK(value)
```

```excel
=ISBLANK(B1)                  // TRUE when B1 is empty
=IF(ISBLANK(B1), "", B1*2)    // guard a calculation on an empty input
```

`0`, `FALSE`, a space and errors are not blank.

<Warning>
  The engine reads an empty cell as `""`, so `ISBLANK` is `TRUE` for every
  value that reads as `""`: an empty cell, a cell whose formula returns `""`,
  and `""` itself. Excel returns `TRUE` only for an empty cell, so
  `=ISBLANK("")` and `ISBLANK` of a cell holding `=""` are `FALSE` there.
</Warning>

### Arrays

Both functions test an array argument element by element, and the result
spills with the argument's shape. Aggregates read every cell of a bounded
result, the empty cells of a range included, so `IF` can count with them. Given
`1`, an empty cell, `x` and an empty cell in `A1:A4`:

```excel
=ISBLANK(A1:A4)                    // spills FALSE, TRUE, FALSE, TRUE
=SUM(IF(ISBLANK(A1:A4), 1, 0))     // 2, the empty cells
=SUM(IF(ISNUMBER(A1:A4), 1, 0))    // 1, the numbers
```

An unbounded range such as `A:A` is read by its populated cells, so
`=SUM(IF(ISBLANK(A:A), 1, 0))` counts only the populated cells that read as
`""`.

## `CELL`

Returns information about a reference.

```excel
=CELL(info_type, reference)
```

Supported, verified info types include:

| Formula | Result for `B2 = 10` |
| --- | --- |
| `=CELL("address",B2)` | `"$B$2"` |
| `=CELL("row",B2)` | `2` |
| `=CELL("col",B2)` | `2` |
| `=CELL("contents",B2)` | `10` |
| `=CELL("type",B2)` | type code |

Verified text returned type code `"l"` (label). Numeric, boolean, empty and error
inputs use their engine-defined codes.

<Note>
  `CELL` is a compact compatibility function, not a general metadata API. Use
  `getCellMetadata()` for consumer-defined comments, links or rich content.
</Note>
