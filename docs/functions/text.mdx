## Join text

### `CONCATENATE` / `CONCAT`

`CONCAT` is an alias of `CONCATENATE`.

```excel
=CONCATENATE(text1, [text2], ...)
=CONCAT(text1, [text2], ...)
```

```excel
=CONCATENATE("North","-","South") // "North-South"
=CONCAT("North","/","South")     // "North/South"
```

### `TEXTJOIN`

```excel
=TEXTJOIN(delimiter, ignore_empty, text1, [text2], ...)
```

```excel
=TEXTJOIN(", ",TRUE,A2:A4) // "North, South, North"
```

When `ignore_empty` is `TRUE`, empty cells do not create extra delimiters.
As in Excel, an omitted `delimiter` is empty text and an omitted
`ignore_empty` is `TRUE`:

```excel
=TEXTJOIN(,,A2:A4) // "NorthSouthNorth"
```

## Compare and locate

### `EXACT`

Case-sensitive equality:

```excel
=EXACT("North","North") // TRUE
=EXACT("North","north") // FALSE
```

### `FIND`

```excel
=FIND(find_text, within_text, [start_num])
```

Returns a **1-based** position and is case-sensitive.

```excel
=FIND("o","North") // 2
```

Use `start_num` to begin later in the string. Missing text returns a formula
error. Leaving `start_num` out makes it `1`, but an omitted `start_num`,
written as a trailing comma, is `0`, as in Excel, so `=FIND("o","North",)`
returns `#VALUE!`.

## Slice text

### `LEFT`

```excel
=LEFT(text, [num_chars])
=LEFT("North",3) // "Nor"
```

### `RIGHT`

```excel
=RIGHT(text, [num_chars])
=RIGHT("North",3) // "rth"
```

### `MID`

```excel
=MID(text, start_num, num_chars)
=MID("North",2,3) // "ort"
```

`start_num` is 1-based.

### Omitted counts

Leaving `num_chars` out of `LEFT` or `RIGHT` takes one character. An argument
left empty, as in `=LEFT("North",)`, is `0`, as in Excel:

```excel
=LEFT("North")    // "N"
=LEFT("North",)   // ""
=RIGHT("North",)  // ""
=MID("North",2,)  // ""
=MID("North",,3)  // #VALUE!, start_num 0 is before the first character
```

## Measure text

### `LEN`

```excel
=LEN(text)
=LEN("North") // 5
```

## Format numbers

### `TEXT`

Formats a value as text with an Excel number format code.

```excel
=TEXT(value, format_text)
```

```excel
=TEXT(1234.567,"$#,##0.00")         // "$1,234.57"
=TEXT(0.285,"0.0%")                 // "28.5%"
=TEXT(45000,"dddd, mmmm d, yyyy")   // "Wednesday, March 15, 2023"
="Total: "&TEXT(1234.5,"#,##0")     // "Total: 1,235"
```

Numbers are rounded as Excel shows them, in decimal with 15 significant
digits, with halves rounded away from zero:

```excel
=TEXT(2.675,"0.00")  // "2.68"  (binary rounding gives 2.67)
=TEXT(1.005,"0.00")  // "1.01"
=TEXT(-2.5,"0")      // "-3"
```

A number exactly halfway between two 15-digit decimals shows as the one
nearer zero, as in Excel: `=TEXT(1000000000000005,"0")` is
`"1000000000000000"`.

#### Number codes

| Code | Shows | Example | Result |
| --- | --- | --- | --- |
| `0` | a digit, or `0` | `=TEXT(5,"000")` | `"005"` |
| `#` | a digit, or nothing | `=TEXT(0.5,"#.##")` | `".5"` |
| `?` | a digit, or a space | `=TEXT(1.5,"??.??")` | `" 1.5 "` |
| `.` | the decimal point | `=TEXT(1234,".0")` | `"1234.0"` |
| `,` between digits | thousands separators | `=TEXT(1234567,"#,##0")` | `"1,234,567"` |
| `,` after digits | the number divided by 1000 | `=TEXT(1234567,"0.0,,")` | `"1.2"` |
| `%` | the number multiplied by 100 | `=TEXT(0.256,"0%")` | `"26%"` |
| `E+`, `E-` (also `e+`, `e-`) | scientific notation | `=TEXT(12200000,"0.00E+00")` | `"1.22E+07"` |
| `/` between digits | a fraction | `=TEXT(4.34,"# ?/?")` | `"4 1/3"` |
| `General` | Excel's General format | `=TEXT(1/3,"General")` | `"0.333333333"` |
| `@` | the text value | `=TEXT("abc","@"" units""")` | `"abc units"` |
| `"text"`, `\x` | literal text | `=TEXT(5,"""Well ""00")` | `"Well 05"` |
| `_x` | a space as wide as `x` | `=TEXT(5,"0_)")` | `"5 "` |
| `*x` | nothing: TEXT has no cell to fill | `=TEXT(5,"*-0")` | `"5"` |

The characters `$ - + ( ) : ! ^ & ' ~ { } < > =` and space need no quotes.
Digits fill groups of placeholders separated by text from the right:

```excel
=TEXT(123456789,"000-00-0000")      // "123-45-6789"
=TEXT(5551234567,"(000) 000-0000")  // "(555) 123-4567"
=TEXT(12,"0"" µL""")                // "12 µL"
```

With several integer placeholders, scientific notation uses exponents that
are a multiple of their count. Fractions approximate the number with the
digits shown, or use a fixed denominator:

```excel
=TEXT(12345,"##0.0E+0")     // "12.3E+3"
=TEXT(3.14159,"# ??/??")    // "3  1/7 "
=TEXT(3.14159,"# ?/8")      // "3 1/8"
=TEXT(3.14159,"# ??/100")   // "3 14/100"
```

`General` shows a number in at most 11 characters, with scientific notation
for large and small numbers:

```excel
=TEXT(123456789012,"General")   // "1.23457E+11"
=TEXT(0.00001234567,"General")  // "1.23457E-05"
```

#### Sections and conditions

A format has up to four sections, `positive;negative;zero;text`. The negative
section formats the number without its sign:

```excel
=TEXT(-5,"0;(0);""zero""")          // "(5)"
=TEXT(0,"0;(0);""zero""")           // "zero"
=TEXT("abc","0;0;0;""[""@""]""")    // "[abc]"
```

Without a negative section, a negative number gets a minus sign, but only when
a non-zero digit is shown, as in Excel:

```excel
=TEXT(-0.4,"0")     // "0"
=TEXT(-0.4,"0;-0")  // "-0"
```

Conditions in brackets, at most two, choose the section instead:

```excel
=TEXT(5,"[>=100]0;[<100]0.0")                           // "5.0"
=TEXT(500,"[>=100]0;[<100]0.0")                         // "500"
=TEXT(8675309,"[<=9999999]###-####;(###) ###-####")     // "867-5309"
=TEXT(2813308004,"[<=9999999]###-####;(###) ###-####")  // "(281) 330-8004"
```

Colors such as `[Red]` are ignored, and so are locale tags such as `[$-409]`.
A currency tag shows its symbol, and `[$-F800]` shows the long date:

```excel
=TEXT(-1.5,"[Red]0.00;[Blue]-0.00")         // "-1.50"
=TEXT(5,"[$€-407]0.00")                     // "€5.00"
=TEXT(45000,"[$-F800]dddd, mmmm dd, yyyy")  // "Wednesday, March 15, 2023"
```

#### Dates and times

Dates and times are serial numbers in Excel's 1900 date system: `1` is
1900-01-01 and the fraction is the time of day. As in Excel, `0` is
1900-01-00 and `60` the fictitious 1900-02-29.

| Code | Shows | `45000.75` shows |
| --- | --- | --- |
| `yy`, `yyyy` | the year | `23`, `2023` |
| `m`, `mm` | the month | `3`, `03` |
| `mmm`, `mmmm`, `mmmmm` | the month name | `Mar`, `March`, `M` |
| `d`, `dd` | the day | `15`, `15` |
| `ddd`, `dddd` | the weekday | `Wed`, `Wednesday` |
| `h`, `hh` | the hour | `18`, `18` |
| `m`, `mm` after `h` or before `s` | the minute | `0`, `00` |
| `s`, `ss`, `ss.00` | the second | `0`, `00`, `00.00` |
| `AM/PM`, `A/P` | the 12-hour clock | `PM`, `P` |
| `[h]`, `[m]`, `[s]` | elapsed hours, minutes or seconds | `1080018`, `64801080`, `3888064800` |

```excel
=TEXT(45000.75,"yyyy-mm-dd hh:mm")  // "2023-03-15 18:00"
=TEXT(0.5,"h:mm AM/PM")             // "12:00 PM"
=TEXT(1.5,"[h]:mm")                 // "36:00"
=TEXT(60,"yyyy-mm-dd dddd")         // "1900-02-29 Wednesday"
```

The time is rounded to the seconds shown, or to their fraction, never to
minutes. A time that rounds up to midnight shows the next day:

```excel
=TEXT(0.123456,"h:mm:ss.00")             // "2:57:46.60"
=TEXT(0.99999,"h:mm")                    // "23:59"
=TEXT(45000.9999999,"yyyy-mm-dd hh:mm")  // "2023-03-16 00:00"
```

A date or time format returns `#VALUE!` for a number below `0` or after
9999-12-31 (`2958465`), also for elapsed time:

```excel
=TEXT(-1,"yyyy-mm-dd")  // #VALUE!
=TEXT(-0.5,"[h]:mm")    // #VALUE!
```

#### Arrays

A range or array in either argument is formatted element by element and
broadcast like the operands of an operator; an error in one element stays in
that element. Given `1`, `2.25` and `3` in `A1:A3`:

```excel
=TEXT(A1:A3,"0.0")                      // spills "1.0", "2.3", "3.0"
=TEXT(1.5,{"0","0.0","0.00"})           // spills "2", "1.5", "1.50" across a row
=TEXTJOIN(", ",TRUE,TEXT(A1:A3,"0.0"))  // "1.0, 2.3, 3.0"
```

#### Other values and errors

Text is returned unchanged unless the format has a text section. `TRUE` and
`FALSE` are formatted as the text `"TRUE"` and `"FALSE"`, and `INFINITY` shows
as `"INFINITY"` whatever the format. An omitted `value` is `0` and an omitted
`format_text` is empty, which shows nothing:

```excel
=TEXT("North","0.00")  // "North"
=TEXT(TRUE,"0.00")     // "TRUE"
=TEXT(1/0,"0.00")      // "INFINITY"
=TEXT(,"0.00")         // "0.00"
=TEXT(5,)              // ""
```

An invalid format code returns `#VALUE!`, for example one that mixes date and
number codes or leaves a quote open, and so does a format without a section
for the number:

```excel
=TEXT(5,"yyyy 0")        // #VALUE!
=TEXT(0,"[>0]0;[<0]-0")  // #VALUE!, no section applies to 0
```

<Warning>
  Unlike Excel, `TEXT` does not convert text to a number: `=TEXT("1.5","0.00")`
  returns `"1.5"`, where Excel returns `"1.50"`. An empty cell is empty text,
  so `=TEXT(A1,"0.00")` of an empty `A1` returns `""`, where Excel returns
  `"0.00"`. `format_text` must be text: `=TEXT(5,0)` returns `#VALUE!`, where
  Excel uses the format `"0"`. Month and day names are English and the
  separators are `.` and `,` whatever the locale tag, and `[DBNum1]`,
  `[NatNum1]` and the Hijri calendar `B2` return `#VALUE!`.
</Warning>

## Coercion

Text functions accept cell references and literals. To retain leading zeroes in
input data, store them as strings (`"007"`) rather than numbers. The companion
React grid's `coerceCellInput` helper deliberately preserves leading-zero text.
